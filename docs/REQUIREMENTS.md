# 要求仕様書 (Requirements Specification) — Musubite（結び手）

## 1. プロジェクト概要
**Musubite（結び手）** は、複数の参考資料（PowerPoint `.pptx`、PDF `.pdf`、テキスト/Markdown）とお客様へのヒアリング結果をローカル環境で「結び・繋ぎ・仕立てる」ことで構造化統合し、ワンクリックでクリップボードへ転送して **Claude Desktop** を起動・連携する macOS 向けデスクトップアプリケーションである。

- **リポジトリ**: `https://github.com/Toshiaki0315/Musubite.git`

## 2. ターゲット環境
- **OS**: macOS 13 (Ventura) 以降（Apple Silicon / Intel 対応）
- **連携先アプリ**: Claude Desktop (macOS版)

## 3. 機能要件

### 3.1 ファイル入力・管理機能 (FR-01)
- ドラッグ＆ドロップおよびファイル選択ダイアログから複数ファイルを登録できること。
- 対応フォーマット：`.pptx`, `.pdf`, `.md`, `.txt`, `.csv`
- 登録済みファイルの一覧表示、並び替え、個別削除、全クリアができること。
- フォルダをドロップした場合、配下の対応ファイルを再帰的に抽出できること（任意オプション）。

### 3.2 ヒアリング結果・指示入力機能 (FR-02)
- お客様のヒアリングメモを直接入力・ペーストできるテキストエリアを備えること。
- 用途別のプロンプトテンプレートを選択・編集できること。
  - 例1：新規提案書ドラフト作成（課題整理 → 解決策 → 導入効果）
  - 例2：要件定義・議事録サマリー作成
  - 例3：競合比較・製品特徴マッピング表作成
  - 例4：カスタム指示（自由記述）

### 3.3 ドキュメント構造化・解析エンジン (FR-03)
- **PPTX解析**: スライド番号、スライドタイトル、本文、表（Markdownテーブル化）、スピーカーノートを抽出すること。
- **PDF解析**: ページ番号、テキスト、表データを構造化Markdownとして抽出すること。
- **画像・図表アラート**: テキスト量が極端に少ないページ（画像中心のスライドやスキャンPDF等）を検知し、UI上で「画像主体のページあり（Claude Desktopへの直接画像ドロップ推奨）」と通知すること。

### 3.4 コンテキスト量（トークン数）監視機能 (FR-04)
- 結合後の総文字数および推定トークン数をリアルタイムに表示すること。
- Claudeのコンテキスト上限に近づいた場合（例：100,000トークン超過時）に警告バッジを表示すること。
- トークン削減オプション（「PPTXのスピーカーノートを除外」「空白・装飾の圧縮」）を提供すること。

### 3.5 Claude Desktop 連携機能 (FR-05)
- 「Claudeへ送る」ボタン押下時、以下の処理を連続実行すること：
  1. プロンプトテンプレート ＋ ヒアリングメモ ＋ XMLタグで構造化した全資料データを1つのテキストに結合。
  2. macOSのクリップボードへテキストをコピー。
  3. `open -a "Claude"` を実行し、Claude Desktop を起動または最前面にフォーカス。
  4. （オプションON時）`osascript` 経由で `Cmd+V` を送信し、チャット欄へ自動ペースト。

## 4. 非機能要件
- **セキュリティ・プライバシー**: すべてのファイル解析とテキスト結合はローカル端末内で完結し、外部サーバーへファイルを送信しないこと（ユーザー自身がClaude Desktopへペーストする操作のみ）。
- **パフォーマンス**: 10ファイル（合計50ページ相当）の解析・結合が 3秒以内に完了すること。
- **フェイルセーフ**: macOSの「アクセシビリティ権限」が未許可で自動ペーストが失敗した場合でも、クリップボードへのコピーは必ず完了させ、「クリップボードにコピーしました。Claude Desktopで Cmd+V を押してください」とトースト通知を出すこと。

## 5. 出力コンテキスト構造仕様
クリップボードに格納するテキストは以下のXML構造を標準とする。

```xml
{{selected_prompt_template}}

<hearing_notes>
{{user_hearing_notes}}
</hearing_notes>

<reference_materials>
  <document name="example.pptx" type="pptx" pages="12">
    ## Slide 1: タイトル
    ...
  </document>
  <document name="spec.pdf" type="pdf" pages="5">
    ## Page 1
    ...
  </document>
</reference_materials>
```
